30-second overview

A useful answer depends
on what happened today.

Generic caffeine limits do not answer the immediate question: given my profile, the current time, and what I already consumed, does another drink still make sense?

The tool combines profile, daily log, and beverage estimates in one revisable chain. It is a reference, not a medical decision system.

Current evidence
Working profile, intake log, state, and browser persistence.
AI role
Assisted prototyping and natural input; core rules remain deterministic.

Product logic

Stable rules first,
natural input second.

Personal baseline, daily total, and state feedback are deterministic. Natural language only reduces logging friction and must return its interpretation for correction.
