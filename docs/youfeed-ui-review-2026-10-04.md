# YouFeed 当前界面检查与修复建议

检查日期：2026-10-04。对象：http://127.0.0.1:4173/ 当前本地演示。此次只更新作品集，未修改 YouFeed 产品代码。

## 1. 短屏下文字入口未完整出现在首屏（建议优先处理）

- 复现：以 320×568 CSS 像素打开首页。
- 实测：语音按钮上沿 y=368.48、下沿 y=534.48；“Write a thought”上沿 y=546.48、下沿 y=594.48。文字入口高度 48px，但首屏只显示其顶部，标签不能完整看见，需向下滚动。
- 影响判断：在展会不方便开口的用户可能未立即发现文字路径。这是可见性判断，尚无实际流失数据。
- 建议：为短屏单独收紧产品区、标题区及按钮前的纵向间距，优先使语音与文字两种入口都能完整出现在首屏；保留文字入口的 48px 触控高度。
- 验收：320×568 下两种入口完整可见、不互相覆盖，内容继续自然滚动；390×844 下保留现有主次关系。
- 390×844 截图：[首页](../assets/youfeed/current/home.png)。320px 实测记录见项目 `.design/youfeed-review-2026-10-04/`。

## 2. 完成后的重新开始弹窗仍使用草稿文案（轻量修复）

- 复现：完成一条反馈演示 → “Start a new demo”。
- 实际：弹窗标题为“Start a new demo?”，说明为“Your current feedback will be cleared and the demo settings will reset.”；取消按钮仍叫“Keep my draft”。
- 影响判断：用户已到完成页，但界面又称其为草稿，状态语义不一致。
- 建议：完成状态的取消按钮改为“Stay here”或“Back to confirmation”；说明改为“Start another demo? This resets the current example.”。未完成输入中的清空确认继续使用“Keep my draft”，无需一起修改。
- 验收：从完成页打开重启弹窗时不出现 draft 文案；取消后保持完成页，确认后返回首页并清空当前演示内容。
- 截图：`.design/youfeed-review-2026-10-04/restart-dialog.png`。
