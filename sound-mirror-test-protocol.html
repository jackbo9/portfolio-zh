Sound Mirror / Phase 1 research gate

主持式可用性测试协议

目标样本为 5–8 位真实参与者，每场 25–35 分钟。测试产品而非参与者；录音、录屏和公开脱敏摘要均需明确同意。

本轮验证体验理解与信任，不验证人格模型的心理学效度，也不把主观匹配感解释为科学有效性。

Sample
5–8 人；覆盖不同音乐参与度与语言/文化背景。
Task
无额外解释完成八轮选择，直到参与者认为体验结束。
Metrics
完成率、放弃点、帮助率、坐标理解、匹配感、解释信任。
Privacy
作品集只展示脱敏汇总，不公开姓名、录音或可识别信息。
Session flow
01 / 3–5 min背景访谈

音乐发现、分享行为和对“音乐人格”的第一反应。

02 / 8–12 min无提示任务

观察试听、选择、犹豫、回退、放弃与主持人帮助。

03 / 8–10 min结果理解

解释三条坐标、匹配感、关键选择与信任。

Evidence rules
01

Finding threshold

每条 finding 至少关联两位参与者，或一个严重阻断问题。

02

Traceability

Observation → Interpretation → Design response → Remaining risk 必须分开，并回指 Session ID。

03

Completion gate

5–8 场记录、指标汇总、至少三条 finding、一处证据驱动变化和最小回归验证全部完成后，才能将结果写回案例。

What will be measured

Task completion, drop-off and recovery, facilitator help, coordinate comprehension, perceived result fit, explanation trust, and completion time.

Publication boundary

No result will be published before 5–8 real consented sessions. Findings must trace back to session evidence, and portfolio material will remain de-identified.
