The context

Feedback belongs
to the moment.

Exhibition reactions are specific and short-lived. YouFeed lets a visitor tap an NFC tag or scan a QR code beside a product, enter a product-bound mobile page, and leave one immediate thought.

I designed and implemented the frontstage mobile experience: touchpoint entry, voice/text capture, transcript review, and critical edge states. Backend transcription and insight generation are project context, not my independent delivery.

Constraint
Short attention, noise, microphone permissions, weak networks, and live footfall.
Contribution
Connected the physical trigger, object context, and feedback flow into one usable path.
Team outcome
Deployments collected 1,000+ project responses; this is a team metric.
Unknown
I did not own the backend model, insight accuracy, or complete analysis loop.
The system

One light touchpoint,
one complete chain.

The frontstage must preserve what is being evaluated before transcription or analysis can make sense. Context is captured at entry, not reconstructed later.

TriggerProduct-bound entry

Each NFC/QR resolves to a specific product and prompt.

CaptureVoice + text fallback

Natural expression first, with an equally complete recovery path.

ReviewVisible transcript

Users can inspect and correct the interpretation before submission.

Three decisions
01

Context before capture

Identify the product and prompt before asking for input, so visitors do not rebuild context and the system does not receive detached text.

02

Voice-first, never voice-only

Text is an equal recovery path for public settings, permission denial, and background noise.

03

Trust through visible states

Reviewable transcripts, editable errors, and an explicit delivered state make system interpretation accountable.

One traceable
evidence chain.

The chain separates field constraints, design judgement, interface change, and the boundary of the published outcome.

EvidenceFeedback decays away from the object

DecisionBind first, capture second

NFC/QR opens the relevant product directly.

ChangeAdd dual input and review

Boundary1,000+ is a project outcome

Reflection

What it demonstrates

I designed the mobile layer as part of a physical–digital service, not as an isolated form.

What remains unknown
